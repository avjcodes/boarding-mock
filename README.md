# Boarding mock

A proposal mockup for a client's website, built on the design the client picked. It is not the live site, and some
statements on it are waiting for the client's confirmation. For adults 21 and older. Every page is marked noindex and
robots.txt asks search engines to stay out.

The ship pictures were made with AI. Space pictures: NASA, ESA/Webb and ESO, credited in each page's footer. Not
affiliated with or endorsed by any space agency.
